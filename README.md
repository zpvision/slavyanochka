# Slavyanochka

Сайт фольклорного славянского ансамбля с файловой админкой для управления предстоящими и прошедшими мероприятиями, а также фотогалереей.

## Запуск

```bash
go run .
```

Сайт: <http://localhost:8080>

Админка: <http://localhost:8080/admin/>

Перед публикацией в интернете необходимо заменить временные данные доступа `admin/admin` в `main.go`.
